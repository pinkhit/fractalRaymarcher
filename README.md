Julia fractal set raytraced in real time on GPU. 
Raytracing uses a sphere-based raymarching algorithm to perform intersection tests with the julia set defined in 4D quaternion space, which we then take 3D slices of to render in 3D.
ImGui controls allow for editing fractal parameters in real time, as well as rendering features such as anti-aliasing, raytracing sample count, and colors.
